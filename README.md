# JP McLain — Website starter

A Next.js website starter for JP McLain's Kansas City music lessons and recording studio.

## Run locally

1. Open this folder in Visual Studio Code.
2. Open Terminal → New Terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Visit http://localhost:3000.

## Important

This is a design and interaction prototype. The calendar is **not** connected to real availability, the contact form **does not send messages**, and no payment processing is enabled. Connect verified booking, email, and payment services before publishing it for customer use. Do not publish JP's private studio address.
